Telegram Bot API

Canal previsto para fase 2; no sustituye la carga manual del MVP.

Pendiente de integrar
En implementación se almacenará como secreto de Dokploy, nunca en código, auditoría ni chats.
  1. El administrador crea el bot con @BotFather.
  2. Entrega el token por un canal seguro al responsable del despliegue.
  3. Se implementa emparejamiento de usuarios mediante código de un solo uso.
  4. Se decide si el bot recibe solicitudes externas o solo apoya la operación interna.
Seguridad: revocar inmediatamente cualquier token expuesto. No registrar tokens, contraseñas ni códigos de emparejamiento en la auditoría.
